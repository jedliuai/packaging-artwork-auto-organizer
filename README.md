# 包装稿自动分类与重命名工具

这是一个基于 Python 和 Tkinter 的桌面小工具，用来批量整理包装稿文件。程序会先让你选择一个目标文件夹，然后递归扫描该文件夹及其所有子文件夹中的文件，按文件名里的关键词识别类型，自动创建产品文件夹，并完成移动与标准化重命名。

适合的典型场景：

- 同一批包装稿散落在多个子文件夹里
- 文件名里包含“说明书”“瓶签”“盒子”“外箱”等类型关键词
- 需要把同一产品的稿件归到同一个文件夹，并统一命名

## 当前功能

- 启动后弹出文件夹选择框，不需要手动改代码路径
- 递归扫描所选目录及全部子目录
- 根据文件名关键词判断稿件类型
- 从文件名中提取产品名，并自动创建对应文件夹
- 将文件移动到对应产品文件夹下
- 按预设规则重命名文件
- 如果目标文件已存在，会跳过并输出提示

## 文件命名规则

程序当前依赖“文件名中包含类型关键词”的方式进行识别。

默认关键词映射如下：

```python
KEYWORD_MAPPING = {
    "烤字": "ceramic baked lettering",
    "瓶签": "Label",
    "盒子": "box",
    "中盒": "box",
    "小盒": "small box",
    "说明书": "insert",
    "外箱": "carton",
}
```

处理逻辑如下：

1. 在文件名中查找第一个命中的关键词
2. 关键词前面的内容视为产品名
3. 去掉产品名前后多余的空格、连字符、下划线和破折号
4. 在当前文件所在目录下创建同名产品文件夹
5. 将文件移动进去，并重命名为映射后的标准名称

例如：

- 原文件：`注射用A产品 说明书.pdf`
- 识别产品名：`注射用A产品`
- 识别类型：`说明书`
- 新路径：`注射用A产品\insert.pdf`

## 运行方式

### 方式一：双击启动脚本

直接双击：

- `一键启动.cmd`

程序会自动调用本机的 `py` 或 `python` 来运行主脚本。

### 方式二：命令行启动

在项目目录打开 PowerShell，执行：

```powershell
python .\包装稿自动分类工具.py
```

```powershell

```

## 使用步骤

1. 启动程序
2. 在弹出的窗口中选择需要整理的总文件夹
3. 等待程序自动扫描、分类、移动和重命名
4. 在终端输出中查看处理结果、跳过原因和冲突提示

## 如何修改规则

如果后续稿件命名规则有变化，只需要修改 `包装稿自动分类工具.py` 顶部配置区。

### 新增或修改关键词

例如把“内托”识别为 `tray`：

```python
KEYWORD_MAPPING = {
    "内托": "tray",
}
```

你只需要把这一项补充进现有字典，不需要改动主流程。

### 调整产品名清洗规则

程序当前会去掉产品名前后的这些字符：

```python
TRIM_SEPARATORS = " -_—–"
```

如果实际文件名里还有其他固定分隔符，可以把对应字符补进去。

## 注意事项

- 程序会直接移动原文件，不是复制
- 建议先在一小批样本文件上试跑，再处理整批文件
- 如果文件名里没有可识别关键词，程序会跳过该文件
- 如果无法从文件名中提取产品名，程序会跳过该文件
- 如果目标位置已经存在同名文件，程序会跳过该文件，避免覆盖

## 常见问题

### 双击后没有反应

先确认本机已安装 Python，并且命令行里可以正常执行以下任意一个命令：

```powershell
python --version
```

或：

```powershell
py --version
```

### 为什么有些文件没有被处理

通常有三种原因：

- 文件名里没有命中关键词
- 关键词前没有可提取的产品名
- 目标文件夹里已经存在同名文件

这些情况程序都会在控制台打印提示。
