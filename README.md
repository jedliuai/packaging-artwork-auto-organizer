# 包装稿自动分组重命名工具

这是一个基于 Python 和 Tkinter 的 Windows 小工具，用来批量整理散放的包装稿文件。

程序启动后会让你选择一个文件夹，然后递归扫描该文件夹及其子文件夹里的文件：

1. 按 `映射表.csv` 识别文件属于哪个产品。
2. 根据映射后的产品名和规格创建产品文件夹。
3. 把对应包装稿移动到产品文件夹里。
4. 按包装稿类型把单个文件重命名为标准文件名。

## 映射表格式

`映射表.csv` 必须放在程序同一目录下，格式如下：

```csv
序号,原包装名中包含文字,转换为名字
1,哌拉西林钠他唑巴坦,PIPTAZ
2,曲松,Ceftriaxone
3,唑林,Cefazolin
4,吡肟,Cefepime
5,奥美,Omeprazole
6,布洛芬,Ibupprofen Tablet
7,奥美拉唑缓释胶囊,Omeprazole Capsule
8,扑热息痛,Paracetamol Tablet
9,阿莫西林胶囊,Amoxicillin Capsule
```

程序会优先匹配更长的产品关键词，避免 `奥美拉唑缓释胶囊` 被较短的 `奥美` 抢先命中。

## 整理示例

原始散放文件：

```text
B261005#263122053-55---布洛芬薄膜片400mg铝箔.pdf
B261005#263122053-55---布洛芬薄膜片400mg说明书.pdf
B261005#263122053-55---布洛芬薄膜片400mg外箱.pdf
B261005#263122053-55---布洛芬薄膜片400mg中盒.pdf
```

整理后：

```text
Ibupprofen Tablet 400mg
├── Label.pdf
├── insert.pdf
├── carton.pdf
└── box.pdf
```

## 文件命名规则

内部文件按文件名中包含的关键词重命名：

```python
FILE_TYPE_MAPPING = {
    "烤字": "ceramic baked lettering",
    "瓶签": "Label",
    "铝箔": "Label",
    "胶囊壳": "capsule shell",
    "盒子": "box",
    "中盒": "box",
    "小盒": "small box",
    "说明书": "insert",
    "外箱": "carton",
}
```

## 项目文件

- `包装稿自动分类工具.py`：主程序
- `包装稿自动分类工具.cmd`：双击启动脚本
- `映射表.csv`：产品名称转换规则

## 运行方式

### 方式一：双击启动

直接双击：

```text
包装稿自动分类工具.cmd
```

### 方式二：命令行启动

在项目目录打开 PowerShell，执行：

```powershell
py .\包装稿自动分类工具.py
```

或者：

```powershell
python .\包装稿自动分类工具.py
```

## 使用步骤

1. 启动程序。
2. 在弹出的窗口中选择散放包装稿所在的文件夹。
3. 等待程序自动创建产品文件夹、移动文件、重命名单个文件。
4. 在输出窗口中查看成功、跳过和冲突提示。

## 注意事项

- 程序会移动文件并改文件名，建议先用一小批样本测试。
- 如果文件名没有命中 `映射表.csv` 的产品规则，会跳过。
- 如果文件名没有命中包装稿类型规则，会跳过。
- 如果目标文件已经存在，会跳过，避免覆盖。
- 空文件夹会在整理结束后自动清理。

## 环境要求

- Windows
- Python 3.10 或以上
- 不需要安装第三方库
